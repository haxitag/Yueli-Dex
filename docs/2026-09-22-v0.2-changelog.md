# Changelog

## v0.2.1 — 2026-09-23 (真机运行验证 + 加固)

Full runtime verification pass: CLI (validate / probe / run / fixtures),
playground (three-tier chain, Choice Debugger, Provider Tester, Rule Tester,
Template Tester) exercised on a real browser + real dev-server logs. Issues
below were reproduced by log replay, fixed, and re-verified end to end.

### Fixed (P0 — crash / uncontrolled errors)

| Issue | Reproduction | Fix |
| --- | --- | --- |
| Deeply-nested request crashed with uncontrolled `RangeError: Maximum call stack size exceeded` (500, no decisionId trail) | `state` nested ~10k deep via `/api/choice` | `canonicalize` / `hashRequest` / `isJsonValue` now depth-bound (`MAX_CANONICALIZE_DEPTH = 512`); `dex.choice()` wraps hash failures in `DexError(INVALID_CHOICE_REQUEST)` with failure receipt + `choice.failed` event |

### Fixed (P1 — functionality / security)

| Issue | Reproduction | Fix |
| --- | --- | --- |
| CLI `run` ignored provider `kind` — every provider became a broken http adapter; `kind:"mock"` failed with misleading credential hint | `yueli-dex run` with mock config → `NO_ELIGIBLE_PROVIDER` | Kind-aware provider builder (`http` / `mock`); unsupported kinds fail fast with a clear recovery hint |
| CLI `run` failures lost the execution trace | Dead-endpoint run printed only the error | `choice.failed` listener + failure receipt printed on error paths |
| SSRF in playground `/api/probe` — server fetched any caller-supplied URL (localhost / RFC1918 / 169.254.169.254 reachable) | `POST /api/probe {"endpoint":"http://169.254.169.254/…"}` | New `ssrf-guard.ts`: public http(s) only; loopback / `.internal` / private v4 (incl. CGNAT) / link-local blocked; `DEX_ALLOW_PRIVATE_PROBE=1` opt-out |
| Empty / malformed JSON body → opaque 500 on `/api/choice` (and siblings) | `curl -d '{bad'` → 500 + stack trace | Shared `readJsonBody` → clean `400 BAD_REQUEST_BODY` on all 5 API routes |
| `/api/rule` with missing `ruleSet` crashed with `Cannot read properties of undefined` | `POST /api/rule {}` | 400 with message |

### Fixed (P2 — experience / correctness of display)

| Issue | Fix |
| --- | --- |
| Choice Debugger defaulted to a dead `localhost:9876` http provider — first "Execute" always failed for new users | Default provider is now the built-in `mock-jev` (zero config, first run succeeds) |
| L1 rule display showed `input.accountPlan` while compiled state key is `accountPlan` | `describeWhen` strips the `input.` prefix — paths now match the state the user sees |

### Verified end to end (log replay after fixes)

- Deep-nesting attack → `400`-style controlled `INVALID_CHOICE_REQUEST` (200 via API envelope), 75ms, no crash
- SSRF probes → blocked with explicit reason; public endpoints still probe normally
- CLI `run` mock → full receipt (`decisionId`, `requestHash`, `attempts`) printed; dead-endpoint run prints failure receipt
- Playground user journey: L1 miss → L1 short-circuit (1ms, zero remote) → L2 mock decision → Receipt with routing trace → L3 scaffold generation — all green
- 155 tests (11 files), fixture suite 5/5 (3 pass, 2 needs-provider, 0 errors)

## v0.2.0 — 2026-09-22

Major correctness + semantic-completeness release. No scope expansion:
the public surface still implements the **Choice-only Decision Execution**
contract from `2026-09-21-yueli-dex-choice-design.md`.

### Bug fixes (P0)

| Issue | Fix |
| --- | --- |
| `realtime-action:airborne-with-hazard-defend` fired without checking hazards | Added `$.input.hazards exists` to the `when` clause |
| `startup-pitch:too-short-to-score` used `op: "exists"` (short-circuited every idea) | New `string_length_lt` operator; rule uses `string_length_lt 50` |
| Failure receipts lost attempts | New `RouteExecutionFailure` carries `attempts` + `RouteFailureReason`; `dex.choice()` catch path preserves both |
| Per-attempt timeout leaked across providers (~3× deadlineMs) | Shared budget: every attempt uses `remaining = deadlineAt - Date.now()`; health probe bounded by `min(remaining, 5000)` |
| Circuit breaker `isOpen()` mutated state → multi-probe race | New explicit `probing` state; `allowProbe()` is atomic single-flight; `probeTimeoutMs` added to `RoutePolicy` |
| `hashRequest()` only sorted top-level keys | New recursive `canonicalize()`; structurally-equal inputs now hash identically; non-JSON values throw |

### Semantic completeness (P1)

| Improvement | Notes |
| --- | --- |
| `orderProviders()` now scores on cost / latency / error rate | New `RoutePolicy.scoring`; new `RouteDecision` + `RoutingTrace` surfaced on `DecisionReceipt.route.routing` |
| Passive observation store | Sliding window per provider (default cap 64); p95 / errorRate / avgLatencyMs |
| Rule action lattice: `reject > constrain > route > shortCircuit` | Same-scope conflict detection; idempotent convergence on same `(questionId, choice)` allowed; cross-template noise filtered |
| `ActionIntent` evidence fields (plugin-sdk minor) | Optional `decisionId / confidence / probabilities / ruleRefs / model` |

### Decision Infrastructure (P2)

| `examples.fixtures` on templates | `compile()` parses fixtures; `TemplateRegistry.getFixtures()` exposes them |
| `TemplateCatalogEntry.fixtureCount` | CLI / playground coverage metadata |
| CLI `yueli-dex fixtures` command | End-to-end fixture evaluation across the templates-core pack; reports `pass / needs_provider / mismatch / error` |
